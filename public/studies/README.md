# Studies hosted inside the portfolio

Create one folder per self-contained study here, for example:

```text
public/studies/climate-atlas/
  index.html
  style.css
  main.js
  data.csv
```

Then point the case JSON to `"href":"./studies/climate-atlas/"`.

For projects with their own Vite build, dependencies or repository, publish them separately and use their complete public URL instead.
